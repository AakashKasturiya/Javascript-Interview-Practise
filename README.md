# 🚀 JavaScript Interview Preparation Repository

This repository contains JavaScript interview questions, machine coding challenges, programming problems, data structures, algorithms, and coding practice organized into separate branches.

## 📂 Branch Structure

| Branch Name | Description |
|-------------|-------------|
| `javascript-machine-coding` | JavaScript Machine Coding Interview Questions & Solutions |
| `javascript-coding-questions` | Frequently Asked JavaScript Coding Questions |
| `javascript-programming-questions` | Core JavaScript Programming Problems |
| `array` | Array Interview Questions & Solutions |
