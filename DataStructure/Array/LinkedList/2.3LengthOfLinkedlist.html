JavaScript Code to Find the Length of a Linked List:

To find the length of a linked list in JavaScript, you can iterate through the list while counting the nodes. Here's how you can implement this:

Explanation:

  • Node class: Represents a node in the linked list with a value and next pointer.
  • LinkedList class:
    • append(): Adds a new node to the end of the list.
    • display(): Displays the list in a readable format.
    • length():
      • This function iterates through the linked list.
      • It starts with the head node and moves through the list, counting each node until the end (null).
      • Finally, it returns the count, which represents the length of the linked list. 
            
            // Define a Node class to represent each node in the linked list
            class Node {
                constructor(value) {
                    this.value = value;
                    this.next = null; // Points to the next node
                }
            }

            // Define a LinkedList class
            class LinkedList {
                constructor() {
                    this.head = null; // The head node of the linked list
                }
               
                // Function to add a node at the end of the list
                append(value) {
                    const newNode = new Node(value);
                    if (this.head === null) {
                        this.head = newNode;
                        return;
                    }
                   
                    let current = this.head;
                    while (current.next) {
                        current = current.next;
                    }
                    current.next = newNode;
                }
               
                // Function to display the linked list
                display() {
                    let current = this.head;
                    let result = '';
                    while (current) {
                        result += current.value + ' -> ';
                        current = current.next;
                    }
                    result += 'null';
                    console.log(result);
                }
               
                // Function to find the length of the linked list
                length() {
                    let current = this.head;
                    let count = 0;
                
                    // Traverse the list and count the nodes
                    while (current !== null) {
                        count++;
                        current = current.next;
                    }
                   
                    return count; // Return the length of the list
                }
            }
            
            // Example usage
            const list = new LinkedList();
            list.append(1);
            list.append(2);
            list.append(3);
            list.append(4);
            list.append(5);
            
            console.log("Original list:");
            list.display();
            
            const len = list.length();
            console.log("Length of the list:", len);
