Search Node in Linked List

let's add a method to search for a node in the linked list based on its value. This method will traverse through the list and check each node to see if its data matches the value we are searching for.

Steps for Search:

1. Start at the head of the list.

2.Traverse through each node and compare its data with the value you're looking for.

3. If a match is found, return the node or simply return true to indicate that the node was found.

4. If the list ends without finding a match, return false or indicate that the node isn't present.

Code with search Method:

            
                class Node {
                    constructor(data) {
                    this.data = data; // Store the data
                    this.next = null; // Reference to the next node (initially null)
                    }
                }
                
                class LinkedList {
                    constructor() {
                    this.head = null; // The head (first node) of the list is initially null
                    }
                
                    // Method to add a node at the end of the list
                    append(data) {
                    const newNode = new Node(data); // Create a new node with the given data
                
                    // If the list is empty, make the new node the head of the list
                    if (this.head === null) {
                        this.head = newNode;
                    } else {
                        let current = this.head;
                        // Traverse to the last node
                        while (current.next !== null) {
                        current = current.next;
                        }
                        // Make the last node's next reference point to the new node
                        current.next = newNode;
                    }
                    }
                
                    // Method to search for a node by its value
                    search(value) {
                    let current = this.head; // Start at the head of the list
                
                    while (current !== null) {
                        if (current.data === value) {
                        return true; // If the value is found, return true
                        }
                        current = current.next; // Move to the next node
                    }
                
                    return false; // If the value isn't found, return false
                    }
                
                    // Method to traverse (display) the entire linked list
                    traverse() {
                    let current = this.head;
                
                    if (current === null) {
                        console.log("The list is empty.");
                        return;
                    }
                
                    while (current !== null) {
                        console.log(current.data);
                        current = current.next;
                    }
                    }
                }

Explanation of the search Method:

  • 1. Start at the head: We begin at the head of the linked list (let current = this.head).
  • 2. Traverse the list:
    • We use a while loop to go through each node in the list.
    • For each node, we check if the data of the current node matches the value we are searching for (if (current.data === value)).
  • 3. Return the result:
    • If a match is found, the method returns true.
    • If we reach the end of the list (i.e., current === null) and haven’t found a match, we return false, indicating the value is not present in the list.

Example Usage:

            
                const list = new LinkedList();

                // Append nodes
                list.append(10);
                list.append(20);
                list.append(30);
                list.append(40);
                
                // Traverse and print the list
                console.log("Linked list:");
                list.traverse();
                
                // Search for a node
                console.log("Searching for 20:", list.search(20)); // Should return true
                console.log("Searching for 50:", list.search(50)); // Should return false

Output

            
                Linked list:
                10
                20
                30
                40
                Searching for 20: true
                Searching for 50: false

Key Points:

Search logic: The method simply traverses the list from the head and checks each node's data to see if it matches the search value.

Efficiency: The search operates in linear time, meaning its time complexity is O(n), where n is the number of nodes in the list.

Return value: The method returns true if the value is found and false if the value is not found.
