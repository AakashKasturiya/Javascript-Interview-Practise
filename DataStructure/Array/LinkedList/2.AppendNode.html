Linked List with Only the append Method:

The append method for the linked list class, keeping it focused on adding elements to the list. 

        
          class Node {
            constructor(data) {
              this.data = data; // Store the data
              this.next = null; // Reference to the next node (initially null)
            }
          }
          
          class LinkedList {
            constructor() {
              this.head = null; // The head (first node) of the list is initially null
            }
          
            // Method to add a node at the end of the list
            append(data) {
              const newNode = new Node(data); // Create a new node with the given data
          
              // If the list is empty, make the new node the head of the list
              if (this.head === null) {
                this.head = newNode;
              } else {
                let current = this.head;
                // Traverse to the last node
                while (current.next !== null) {
                  current = current.next;
                }
                // Make the last node's next reference point to the new node
                current.next = newNode;
              }
            }
          }

How to Use It:

          
            const list = new LinkedList();

            // Append nodes
            list.append(10);
            list.append(20);
            list.append(30);
            
            // At this point, the list has nodes with data 10 -> 20 -> 30

What’s Happening:

append - This method adds a new node to the end of the list. It checks if the list is empty (i.e., the head is null). If it is, the new node becomes the head. Otherwise, it traverses to the end of the list and links the new node there.
