Remove Node Linked List method

let's implement the remove method for the linked list. This method will allow us to remove a node based on its value from the linked list.

Steps to Remove a Node:

  • Check if the list is empty: If the list is empty, there’s nothing to remove.
  • Find the node to remove:
    • If the node to remove is the head (the first node), we just need to update the head to the next node.
    • If the node is not the head, we need to traverse the list and find the node just before the one we want to remove. Once we find it, we update the next reference of the previous node to skip the node we want to remove.
  • Edge cases:
    • Removing a node that doesn't exist in the list.
    • Removing the last node.

Code with the remove Method:

        
            class Node {
                constructor(data) {
                  this.data = data; // Store the data
                  this.next = null; // Reference to the next node (initially null)
                }
              }
              
              class LinkedList {
                constructor() {
                  this.head = null; // The head (first node) of the list is initially null
                }
              
                // Method to add a node at the end of the list
                append(data) {
                  const newNode = new Node(data); // Create a new node with the given data
              
                  // If the list is empty, make the new node the head of the list
                  if (this.head === null) {
                    this.head = newNode;
                  } else {
                    let current = this.head;
                    // Traverse to the last node
                    while (current.next !== null) {
                      current = current.next;
                    }
                    // Make the last node's next reference point to the new node
                    current.next = newNode;
                  }
                }
              
                // Method to remove a node by its value
                remove(value) {
                  if (this.head === null) {
                    console.log("The list is empty.");
                    return;
                  }
              
                  // If the node to be removed is the head node
                  if (this.head.data === value) {
                    this.head = this.head.next; // Move the head to the next node
                    console.log(`Node with value ${value} removed.`);
                    return;
                  }
              
                  let current = this.head;
                  let previous = null;
              
                  // Traverse the list to find the node to remove
                  while (current !== null && current.data !== value) {
                    previous = current;  // Keep track of the previous node
                    current = current.next; // Move to the next node
                  }
              
                  // If we reach the end of the list without finding the value
                  if (current === null) {
                    console.log(`Node with value ${value} not found.`);
                    return;
                  }
              
                  // Remove the node by skipping it
                  previous.next = current.next;
                  console.log(`Node with value ${value} removed.`);
                }
              
                // Method to traverse (display) the entire linked list
                traverse() {
                  let current = this.head;
              
                  if (current === null) {
                    console.log("The list is empty.");
                    return;
                  }
              
                  while (current !== null) {
                    console.log(current.data);
                    current = current.next;
                  }
                }
              }

Explanation of the remove Method:

  • 1. Check if the list is empty: 
                    
                    if (this.head === null) {
                        console.log("The list is empty.");
                        return;
                      }
    If the list is empty, we simply log a message and return because there’s nothing to remove.
  • Removing the head node: 
                    
                    if (this.head.data === value) {
                        this.head = this.head.next; // Update the head to the next node
                        console.log(`Node with value ${value} removed.`);
                        return;
                      }
    If the node to be removed is the head node, we update the head to point to the next node in the list.
  • Traverse to find the node: 
                    
                    let current = this.head;
                    let previous = null;
                    
                    while (current !== null && current.data !== value) {
                      previous = current;  // Keep track of the previous node
                      current = current.next; // Move to the next node
                    }
    We start at the head and move through the list, keeping track of the previous node. If we find the node with the specified value, we can remove it.
  • If the node is found, remove it: 
                    
                    if (current === null) {
                        console.log(`Node with value ${value} not found.`);
                        return;
                      }
                      
                      previous.next = current.next; // Skip the current node to remove it
    If the node is found, we update the next reference of the previous node to point to the node after the one we want to remove. This effectively removes the node from the list.

Example Usage:

         
            const list = new LinkedList();

            // Append nodes
            list.append(10);
            list.append(20);
            list.append(30);
            list.append(40);
            
            // Traverse and print the list before removal
            console.log("Before removal:");
            list.traverse();
            
            // Remove a node
            list.remove(20); // Remove node with value 20
            
            // Traverse and print the list after removal
            console.log("After removal:");
            list.traverse();
            
            // Attempt to remove a node that doesn't exist
            list.remove(50);

Output

         
            Before removal:
            10
            20
            30
            40
            Node with value 20 removed.
            After removal:
            10
            30
            40
            Node with value 50 not found.

Key Points:

Removing the head:If the node to be removed is the head, we just update the head pointer to the next node.

Removing other nodes: If the node to be removed is the head, we just update the head pointer to the next node.

Edge cases: We handle scenarios where the node isn't found or the list is empty.
