To insert a node at any point in the linked list, we need to insert a new node at a specific position rather than always at the end (like in the append method). This insertion can be at the beginning, middle, or end of the list.
Here's how we can do it:

Insertion at Any Point in the Linked List:

1. Inserting at the beginning: If the position is 0 (or if we want to insert at the beginning), we simply make the new node the head of the list.

2. Inserting at a specific position: If the position is in the middle or end, we need to traverse the list to find the node just before the insertion point, and then update the next references accordingly.

Steps:

  • Check if the list is empty: If the list is empty, there’s nothing to remove.
  • Find the node to remove:
    • Create the new node with the data you want to insert.
    • Check if the position is valid (e.g., non-negative position).
    • Traverse the list to find the correct spot
      • If the position is 0, insert at the beginning.
      • Otherwise, traverse to the node just before the specified position.
    • Update the next references to insert the new node at the right place.

Code with insertAt Method:

        
            class Node {
                constructor(data) {
                  this.data = data; // Store the data
                  this.next = null; // Reference to the next node (initially null)
                }
              }
              
              class LinkedList {
                constructor() {
                  this.head = null; // The head (first node) of the list is initially null
                }
              
                // Method to add a node at the end of the list
                append(data) {
                  const newNode = new Node(data); // Create a new node with the given data
              
                  // If the list is empty, make the new node the head of the list
                  if (this.head === null) {
                    this.head = newNode;
                  } else {
                    let current = this.head;
                    // Traverse to the last node
                    while (current.next !== null) {
                      current = current.next;
                    }
                    // Make the last node's next reference point to the new node
                    current.next = newNode;
                  }
                }
              
                // Method to insert a node at a specific position
                insertAt(data, position) {
                  const newNode = new Node(data); // Create a new node
              
                  // If the position is invalid (negative position)
                  if (position < 0) {
                    console.log("Invalid position.");
                    return;
                  }
              
                  // If inserting at the beginning (position 0)
                  if (position === 0) {
                    newNode.next = this.head; // Make the new node point to the current head
                    this.head = newNode; // Update the head to the new node
                    console.log(`Node with value ${data} inserted at position 0.`);
                    return;
                  }
              
                  let current = this.head;
                  let index = 0;
              
                  // Traverse the list to find the node just before the desired position
                  while (current !== null && index < position - 1) {
                    current = current.next;
                    index++;
                  }
              
                  // If we reached the end of the list and the position is out of bounds
                  if (current === null) {
                    console.log("Position out of bounds.");
                    return;
                  }
              
                  // Insert the new node at the desired position
                  newNode.next = current.next; // Make the new node point to the next node
                  current.next = newNode; // Make the previous node point to the new node
                  console.log(`Node with value ${data} inserted at position ${position}.`);
                }
              
                // Method to traverse (display) the entire linked list
                traverse() {
                  let current = this.head;
              
                  if (current === null) {
                    console.log("The list is empty.");
                    return;
                  }
              
                  while (current !== null) {
                    console.log(current.data);
                    current = current.next;
                  }
                }
              }

Explanation of the insertAt Method:

  • 1. Input Parameters:
    • data: The data that will be stored in the new node.
    • position: The index where the new node will be inserted (0-based).
  • 2. Creating the New Node:
    • We create a new node with the given data: const newNode = new Node(data).
  • 3. Checking for Invalid Position:
    • If the position is negative (position < 0), we print an error message because positions must be non-negative.
  • 4. Inserting at the Beginning:
    • If the position is 0, we insert the new node at the beginning of the list.
    • We make the new node's next reference point to the current head of the list, and then we update the head to the new node.
  • 5. Inserting at Other Positions: We traverse the list until we reach the node just before the desired position (position - 1). Once we reach that node, we set: newNode.next = current.next: This makes the new node point to the next node (the one currently at the specified position). current.next = newNode: This links the previous node to the new node, effectively inserting it in the list.
  • 6. Edge Case: Position Out of Bounds:
    • If we reach the end of the list (current === null) and haven’t found the specified position, it means the position is out of bounds, and we print an error message.

Example Usage:

         
            const list = new LinkedList();

            // Append nodes
            list.append(10);
            list.append(20);
            list.append(30);
            list.append(40);
            
            // Traverse and print the list before insertion
            console.log("Before insertion:");
            list.traverse();
            
            // Insert a node at position 2
            list.insertAt(25, 2);
            
            // Traverse and print the list after insertion
            console.log("After insertion at position 2:");
            list.traverse();
            
            // Insert a node at position 0 (beginning)
            list.insertAt(5, 0);
            
            // Traverse and print the list after inserting at the beginning
            console.log("After insertion at position 0:");
            list.traverse();
            
            // Attempt to insert at an out-of-bounds position
            list.insertAt(50, 10);  // This should give an error

Key Points:

Inserting at the beginning: If position is 0, the new node becomes the head of the list.

Inserting at the middle or end: We find the correct position by traversing the list, then adjust the pointers to insert the new node.

Edge cases: We handle invalid positions (negative or out of bounds).
