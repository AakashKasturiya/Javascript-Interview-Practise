Find the average of the numbers in the numbered array?

To find the average of the numbers in an array, you can sum all the values and then divide by the length of the array. Here's how you can do it in JavaScript:

        
        const numbers = [1, 2, 3, 4, 5];
        // Sum all numbers
        const sum = numbers.reduce((acc, curr) => acc + curr, 0);
        
        // Calculate the average
        const average = sum / numbers.length;
        
        console.log(average); // Output: 3
