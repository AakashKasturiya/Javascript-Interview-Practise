How to make a sentence out of the given string array?

To make a sentence out of a given string array, you can use the join() method to combine the strings into one sentence and then add a period at the end if needed.

        
            const words = ["hello", "world", "this", "is", "javascript"];

            // Join the words into a sentence
            const sentence = words.join(" ") + "."; // Adds a space between words and a period at the end
            
            console.log(sentence); // Output: "hello world this is javascript."
