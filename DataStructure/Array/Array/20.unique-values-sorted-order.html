How to find unique values from an Array in sorted order?

✅ Method: Using Set and sort()

        
            const numbers = [5, 3, 2, 2, 4, 1, 5, 3];
            const uniqueSortedNumbers = [...new Set(numbers)].sort((a, b) => a - b);
            console.log(uniqueSortedNumbers); // [1, 2, 3, 4, 5]

🔄 For Descending Order:

        
            const numbers = [5, 3, 2, 2, 4, 1, 5, 3];
            const uniqueSortedNumbers = [...new Set(numbers)].sort((a, b) => b - a);
            console.log(uniqueSortedNumbers); // [1, 2, 3, 4, 5]
