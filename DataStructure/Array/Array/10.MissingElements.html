How to Find missing elements in a given Array 1 to 10

❌ Why is this slow?

        includes() checks each number in givenArray one by one.
    
        If givenArray has N elements, each .includes() call takes O(N) time.
    
        Total complexity: O(N²) in worst case.
✅ Why is Set faster?

Set has O(1) lookups:

    arrSet.has(num) checks if a number exists instantly, unlike includes(), which scans the array.

Set avoids repeated searches:

    We preprocess the array into a Set (O(N)) once.

    Then, we check for missing numbers in a loop (O(M), where M is the range size).

Total time complexity:

    Using includes(): O(N²)

    Using Set: O(N) + O(M) ≈ O(N), which is much faster!
