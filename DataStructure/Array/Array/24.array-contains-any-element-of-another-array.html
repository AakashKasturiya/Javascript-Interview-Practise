How to check if an array contains any element of another array?

To check if an array contains any element of another array, you can use JavaScript's some() method combined with includes().

        
            const array1 = [1, 2, 3, 4, 5];
            const array2 = [3, 6, 7];
            
            // Check if any element in array2 exists in array1
            const containsAny = array2.some(element => array1.includes(element));
            
            console.log(containsAny); // Output: true (since 3 is in both arrays)
Explanation:
  • array2.some(): Loops over array2 and checks if any element satisfies the condition.
  • array1.includes(element): Checks if the current element from array2 exists in array1.
