Given an array of strings, reverse each word in the sentence?

To reverse each word in an array of strings (treating the array as a sentence), you can use the map() function to reverse each word individually and then join them back into a sentence.

    
        const words = ["hello", "world", "this", "is", "javascript"];
        // Reverse each word in the array
        const reversedWords = words.map(word => word.split('').reverse().join(''));
        
        // Join the reversed words into a sentence
        const sentence = reversedWords.join(" ");
        
        console.log(sentence); // Output: "olleh dlrow siht si tpircsavaj"
