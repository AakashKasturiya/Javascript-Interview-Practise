How can you replace an existing element in an object?

1. Using Dot Notation

You can use dot notation to directly replace the value of an existing property.

        
            let obj1 = { name: "John", age: 30 };
            obj1.age = 35;  // Replacing the value of the 'age' property
            console.log(obj1);  // { name: "John", age: 35 }

2. Using Bracket Notation

You can also use bracket notation to replace the value of an existing property, especially useful when the property name is stored in a variable or is not a valid identifier.

        
            let obj2 = { name: "John", age: 30 };
            obj2["age"] = 35;  // Replacing the value of the 'age' property
            console.log(obj2);  // { name: "John", age: 35 }

3. Using Object.assign()

If you're merging objects and want to replace an existing property with a new value, you can use Object.assign().

        
            let obj3 = { name: "John", age: 30  };
            Object.assign(obj3, { age: 35 });  // Replacing the value of the 'age' property
            console.log(obj3);  // { name: "John", age: 35 }

4. Using the Spread Operator (...)

You can use the spread operator to create a new object and replace specific properties.

        
            let obj4 = { name: "John", age: 30  };
            obj4 = { ...obj4, age: 35 }; // Replacing the value of the 'age' property
            console.log(obj4);  // { name: "John", age: 30 }

5. Using Object.defineProperty()

If you need to have more control over the property’s attributes (like whether it’s writable, enumerable, or configurable), you can use Object.defineProperty().

        
            let obj5 = { name: "John", age: 30 };
            Object.defineProperty(obj5, 'age', { value: 35, writable: true });
            console.log(obj5);  // { name: "John", age: 35 }
