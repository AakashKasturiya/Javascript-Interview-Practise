How can you add an element to an object?

1. Using Dot Notation

You can directly assign a new key-value pair to the object using dot notation.

        
            let obj = { name: "John" };
            obj.age = 30;  // Adding a new property 'age' to the object
            console.log(obj);  // { name: "John", age: 30 }

2. Using Bracket Notation

Bracket notation allows you to add properties with keys that might be dynamic or not valid as identifiers (such as names with spaces or special characters).

        
            let obj = { name: "John" };
            obj[age] = 30;  // Adding a new property 'age' to the object
            console.log(obj);  // { name: "John", age: 30 }

3. Using Object.assign()

Object.assign() can be used to add new properties to an existing object by merging another object into it.

        
            let obj2 = { name: "John" };
            Object.assign(obj2, { age: 30 });  // Adding a new property 'age'
            console.log(obj2);  // { name: "John", age: 30 }

4. Using the Spread Operator (...)

You can also use the spread operator to create a new object with additional properties.

        
            let obj3 = { name: "John" };
            obj3 = { ...obj, age: 30 };  // Adding a new property 'age' using the spread operator
            console.log(obj3);  // { name: "John", age: 30 }

5. Using Object.defineProperty()

Object.defineProperty() allows for more control over the properties you add, such as defining whether the property is writable, enumerable, or configurable.

        
            let obj4 = { name: "John" };
            Object.defineProperty(obj4, 'age', { value: 30, writable: true });
            console.log(obj4);  // { name: "John", age: 30 }
