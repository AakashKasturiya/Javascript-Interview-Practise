What is the easiest way to convert an array to an object?

1. Using Object.fromEntries()

If you have an array of key-value pairs, Object.fromEntries() is the most straightforward and modern way to convert it into an object.

        
            const arr = [['name', 'Alice'], ['age', 25]];

            const obj = Object.fromEntries(arr);
            console.log(obj); 
            // Output: { name: 'Alice', age: 25 }

This method works best when the array is an array of pairs (arrays with two elements: [key, value]).

2. Using reduce()

If you have an array of values and you want to convert it to an object (e.g., assigning keys), you can use reduce().

        
            const arr = ['name', 'age'];
            const obj = arr.reduce((acc, cur, index) => {
              acc[`key${index + 1}`] = cur;
              return acc;
            }, {});
            
            console.log(obj);
            // Output: { key1: 'name', key2: 'age' }

This is useful if you want to dynamically assign keys or transform the values.

3. Using map() with Object.assign() (for key-value from array of arrays)

If you have an array and need to convert it to an object, you can use map() and Object.assign(). This is not as modern as Object.fromEntries(), but it works just as well. 

        
            const arr = [['name', 'Alice'], ['age', 25]];

            const obj = Object.assign({}, ...arr.map(([key, value]) => ({ [key]: value })));
            
            console.log(obj);
            // Output: { name: 'Alice', age: 25 }

4. Using forEach()

You can also loop through the array and manually add each key-value pair to an empty object.

        
            const arr = [['name', 'Alice'], ['age', 25]];

            const obj = {};
            arr.forEach(([key, value]) => {
              obj[key] = value;
            });
            
            console.log(obj);
            // Output: { name: 'Alice', age: 25 }
  • Object.fromEntries() is the easiest and most modern method, especially for converting an array of key-value pairs.
  • reduce() is more flexible and powerful, especially if you need to do some transformation on the keys or values.
  • map() + Object.assign() and forEach() are useful, but they are less concise than the other methods.
