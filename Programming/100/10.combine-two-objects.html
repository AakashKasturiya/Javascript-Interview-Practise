How can you combine two objects?

In JavaScript, you can combine (or merge) two objects using a few different methods. Below are the most common approaches:

1. Using Object.assign()

The Object.assign() method copies all properties from one or more source objects into a target object. This method mutates the target object by adding or updating properties.

        
            let obj1 = { name: "John", age: 30 };
            let obj2 = { occupation: "Engineer", city: "New York" };
            
            let combined = Object.assign({}, obj1, obj2); // Creates a new object
            console.log(combined); // { name: "John", age: 30, occupation: "Engineer", city: "New York" }

Note: You can also mutate an object directly by passing the target object as the first argument to Object.assign().

      
        Object.assign(obj1, obj2); // obj1 is now mutated
        console.log(obj1); // { name: "John", age: 30, occupation: "Engineer", city: "New York" }

2. Using the Spread Operator (...)

The spread operator (...) creates a shallow copy of the objects and merges them. This is one of the most modern and commonly used methods.

        
            let obj1 = { name: "John", age: 30 };
            let obj2 = { occupation: "Engineer", city: "New York" };
            
            let combined = { ...obj1, ...obj2 }; // Creates a new object
            console.log(combined); // { name: "John", age: 30, occupation: "Engineer", city: "New York" }

3. Using concat() with Arrays of Objects

If you have an array of objects and want to merge them into a single object, you can use concat() and then reduce them into a single object. This is less common for simple object merging, but can be useful in some scenarios. 

        
            let obj1 = { name: "John" };
            let obj2 = { age: 30 };
            let obj3 = { city: "New York" };
            
            let combined = [obj1, obj2, obj3].reduce((acc, obj) => ({ ...acc, ...obj }), {});
            console.log(combined); // { name: "John", age: 30, city: "New York" }

4. Using Object.defineProperties() (For Adding Specific Properties)

You can use Object.defineProperties() if you need to combine objects in a more controlled way (e.g., adding getters, setters, or specific property descriptors).

        
            let obj1 = { name: "John" };
            let obj2 = { age: 30 };
            
            Object.defineProperties(obj1, Object.getOwnPropertyDescriptors(obj2));
            console.log(obj1); // { name: "John", age: 30 }

5. Using for...in Loop (Custom Approach)

You can also merge objects manually using a for...in loop if you need custom logic for combining the objects (though this is rarely needed due to the above methods).

        
            let obj1 = { name: "John" };
            let obj2 = { age: 30 };
            
            for (let key in obj2) {
              obj1[key] = obj2[key];
            }
            
            console.log(obj1); // { name: "John", age: 30 }
