What is the main difference between Object.values and Object.entries method?

🔍 This dives into object mutability and extensibility, which is often used when dealing with security or strict object control in JavaScript.

✅ To check if an object can be extended (i.e., you can add new properties to it):

        
            Object.isExtensible(obj);

It returns:

  • true → you can add new properties
  • false → the object is not extensible

🧪 Example:

        
            onst obj = { name: "Alice" };

            console.log(Object.isExtensible(obj)); // true
            
            obj.age = 30; // ✅ Allowed

❌ Preventing extensibility:

        
            Object.preventExtensions(obj);
            console.log(Object.isExtensible(obj)); // false
            
            obj.city = "NY"; // ❌ Won’t be added
            console.log(obj.city); // undefined
