How do you define property on an Object constructor ?

In JavaScript, when defining properties within an Object constructor, you typically define them inside the constructor function by using the this keyword. The this keyword refers to the current instance of the object being created.

Explanation:

Constructor Function:

The Person function is a constructor that initializes the properties name and age using this.

When you create a new instance of Person (e.g., new Person('John Doe', 30)), JavaScript creates a new object and assigns the values of name and age to that object.

this Keyword:

Inside the constructor function, the this keyword is used to set the properties (name and age) of the newly created object. This means each object created with the Person constructor will have its own name and age properties.

Using Classes (ES6+):

If you are using ES6 or later, you can use the class syntax to define the constructor and properties more cleanly. The behavior is very similar to the function constructor.
