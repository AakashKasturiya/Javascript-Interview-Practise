How do you prevent an object from extending?

✅ Use Object.preventExtensions(obj)

This prevents new properties from being added to the object.

        
            const user = { name: "Alice" };

            Object.preventExtensions(user);
            
            user.age = 30; // ❌ This won't be added
            console.log(user.age); // undefined

It returns:

  • true → you can add new properties
  • false → the object is not extensible

🧪 Example:

        
            onst obj = { name: "Alice" };

            console.log(Object.isExtensible(obj)); // true
            
            obj.age = 30; // ✅ Allowed

❌ Preventing extensibility:

        
            Object.preventExtensions(obj);
            console.log(Object.isExtensible(obj)); // false
            
            obj.city = "NY"; // ❌ Won’t be added
            console.log(obj.city); // undefined
