How do you copy properties from one object to another object?

🔁 1. Using Object.assign() (shallow copy)

        
            const target = {};
            const source = { a: 1, b: 2 };
            
            Object.assign(target, source);
            
            console.log(target); // { a: 1, b: 2 }

✅ Simple ⚠️ Shallow copy — nested objects are still references

🧪 2. Using spread operator (shallow copy)

1. Using JSON.stringify (shallowish comparison)

        
            const source = { a: 1, b: 2 };
            const target = { ...source };
            
            console.log(target); // { a: 1, b: 2 }

✅ Cleaner syntax ⚠️ Still shallow copy

🧠 3. Deep copy (for nested objects)

If your object has nested objects and you want a deep copy (not sharing references): Option A: Using structuredClone() (modern browsers)

        
            const original = { a: 1, b: { c: 2 } };
const copy = structuredClone(original);
  • ✅ Handles nested objects
  • ✅ Works regardless of key order
  • ⚠️ Slower for large structures

Bonus: For interview flex 💪

If they ask you about comparing two objects like:

        
            const obj1 = { a: 1, b: { c: 2 } };
            const obj2 = { a: 1, b: { c: 2 } };

✅ Deep copy ✅ Preserves structure ⚠️ Not supported in older environments (like some Node.js versions or older browsers)

Option B: Using JSON.parse(JSON.stringify(obj))

        
            const copy = JSON.parse(JSON.stringify(original));

⚠️ Doesn’t work with functions, undefined, Date, Map, Set, etc.

Bonus: Merge two objects

        const obj1 = { a: 1 };
            const obj2 = { b: 2 };
            const merged = { ...obj1, ...obj2 };
            
            console.log(merged); // { a: 1, b: 2 }

Interview Tip 💡 If asked in an interview:

"To copy properties from one object to another, I can use Object.assign() or the spread operator for a shallow copy. For deep copies, I’d use structuredClone() or a utility like lodash.cloneDeep()."
