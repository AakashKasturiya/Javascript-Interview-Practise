How do you determine whether an object is frozen or not?

In JavaScript, you can determine whether an object is frozen using the built-in Object.isFrozen() method.

Object.isFrozen() Method

The Object.isFrozen() method checks whether an object is frozen. An object is considered frozen if:

  • Its properties cannot be added or removed.
  • Its existing properties cannot be modified.
  • Its prototype cannot be modified.

If an object is frozen, Object.isFrozen() will return true; otherwise, it will return false.

        
            Object.isFrozen(obj);

Example: Object with Method Chaining

Here’s how you can implement an object with multiple functions that can be chained together:

        
            const obj1 = { name: 'John', age: 30 };

            // Freezing the object
            Object.freeze(obj1);
            
            console.log(Object.isFrozen(obj1)); // true
            
            const obj2 = { name: 'Alice', age: 25 };
            
            console.log(Object.isFrozen(obj2)); // false

Explanation:

Object.freeze() makes the object immutable by freezing it, meaning you can no longer add, delete, or modify the properties of the object.

Object.isFrozen() checks if an object is frozen and returns true if it is, otherwise it returns false.

Freezing an Object:

You can freeze an object using Object.freeze() like so:

        
            const obj = { name: 'John', age: 30 };

            Object.freeze(obj);
            
            console.log(Object.isFrozen(obj)); // true
            
            // Attempting to modify the object will fail in strict mode
            obj.name = 'Alice'; // Does not work
            console.log(obj.name); // "John" (remains unchanged)
            
            obj.address = 'New York'; // Does not work, new properties can't be added
            console.log(obj.address); // undefined
