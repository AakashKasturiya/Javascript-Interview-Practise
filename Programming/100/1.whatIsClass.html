How to define a class with properties and methods in JavaScript?

Basic Explanation:

A class in JavaScript is a blueprint for creating objects with specific properties and methods. The constructor is used to initialize the object when it's created, and methods define actions that the object can perform.

Syntax to Define a Class with Properties and Methods:

Properties: These are defined inside the constructor method (or directly on the object using this).

Methods: These are defined directly inside the class body, without the function keyword.
