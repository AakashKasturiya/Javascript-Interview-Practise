What is the main difference between Object.values and Object.entries method?

🔑Object.values and Object.entries

🔍 Both Object.values() and Object.entries() are used to access an object's enumerable own properties, but they return different formats of data.

👉 Use Object.values() when you only care about the values

        
            const user = { name: "Alice", age: 25 };
            console.log(Object.values(user));

👉 Object.entries(user):

        
            const user = { name: "Alice", age: 25 };
            console.log(Object.entries(user));
            // Output: [["name", "Alice"], ["age", 25]]

👉Use Object.entries() when you need both key and value — e.g. in loops or mapping

        
            Object.entries(user).forEach(([key, value]) => {
                console.log(`${key}: ${value}`);
              });

✅ To get the list of keys (property names) of an object:

        
            const person = {
                name: "Alice",
                age: 30
              };
              
              const keys = Object.keys(person);
              console.log(keys); // ['name', 'age']
