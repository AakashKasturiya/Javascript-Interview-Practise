How to find duplicate elements in a given array?

✅ 1. Using a Set (Fast and Efficient)

        
            function findDuplicates(arr) {
                const seen = new Set();
                const duplicates = new Set();
              
                for (const item of arr) {
                  if (seen.has(item)) {
                    duplicates.add(item);
                  } else {
                    seen.add(item);
                  }
                }
              
                return Array.from(duplicates);
              }
              
              // Example:
              console.log(findDuplicates([1, 2, 3, 4, 2, 3, 5])); // [2, 3]
  • Time complexity: O(n)
  • Space complexity: O(n)
  • Why it's good: Very efficient and readable. Uses built-in structures.

✅ 2. Using a Frequency Map (for counts too)

        
            function findDuplicates(arr) {
                const freqMap = {};
                const result = [];
              
                for (let item of arr) {
                  freqMap[item] = (freqMap[item] || 0) + 1;
                }
              
                for (let key in freqMap) {
                  if (freqMap[key] > 1) {
                    result.push(Number(key)); // convert back to number if needed
                  }
                }
              
                return result;
              }
              
              // Example:
              console.log(findDuplicates([1, 2, 3, 4, 2, 3, 5])); // [2, 3]

Bonus: You can return counts too if asked.

✅ 3. Using filter and indexOf (Less Efficient, More Functional Style)

        
            function findDuplicates(arr) {
                return arr.filter((item, index) => arr.indexOf(item) !== index)
                          .filter((item, index, self) => self.indexOf(item) === index);
              }
              
              // Example:
              console.log(findDuplicates([1, 2, 3, 4, 2, 3, 5])); // [2, 3]
  • Time complexity: O(n²) in worst case
  • Why use it: Shows understanding of array methods, but not ideal for large arrays.
