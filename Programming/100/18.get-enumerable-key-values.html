How do you get an enumerable key and value pairs?

🔑 What does enumerable mean?

An enumerable property is one that will show up when you're iterating over an object using loops like for...in, or methods like Object.keys(), etc.

✅ To get enumerable key-value pairs:

You can use:

        
            Object.entries(obj)

It returns an array of [key, value] pairs for all own enumerable properties of the object.

✅ Example:

        
            const user = {
                name: "Alice",
                age: 25
              };
              
              console.log(Object.entries(user));
              // Output: [['name', 'Alice'], ['age', 25']]

You can loop over it:

        
            for (const [key, value] of Object.entries(user)) {
                console.log(`${key}: ${value}`);
              }
              // name: Alice
              // age: 25

📌 Bonus: Other related methods

Method What it returns
Object.keys(obj) Array of enumerable property names
Object.values(obj) Array of enumerable values
Object.entries(obj) Array of [key, value] pairs
