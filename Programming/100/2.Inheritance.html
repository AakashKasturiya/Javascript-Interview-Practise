How to implement class inheritance in JavaScript?

To implement class inheritance in JavaScript, you can use the extends keyword to create a child class that inherits from a parent class. This allows the child class to access all the properties and methods of the parent class, and you can also override or extend those methods in the child class. Here’s a step-by-step explanation of how to implement class inheritance in JavaScript:

Steps for Class Inheritance:

Create a Parent Class: This is the base class that contains common properties and methods.

Create a Child Class: This class extends the parent class using the extends keyword.

Use super(): The super() keyword is used to call the constructor of the parent class from the child class and also to call parent methods from the child class.
