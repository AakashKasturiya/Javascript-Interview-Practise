How do you determine if an object is sealed or not?

🧊 What does “sealed” mean in JavaScript?

A sealed object:

  • ❌ You can’t add or delete properties
  • ✅ You can still modify existing property values
  • ✅ Property descriptors like writable still apply

🔍 How to check if an object is sealed

        
            Object.isSealed(obj)

Returns true if the object is sealed, false otherwise.

✅ Example:

        
            const person = { name: "Alice" };
            Object.seal(person);
            
            console.log(Object.isSealed(person)); // true
            
            person.name = "Bob";     // ✅ allowed
            delete person.name;      // ❌ not allowed
            person.age = 30;         // ❌ not allowed

❌ Not sealed example:

        
            const openObj = { x: 1 };
            console.log(Object.isSealed(openObj)); // false
            
            openObj.y = 2;         // ✅ allowed
            delete openObj.x;      // ✅ allowed
