Explain what is Object Destructuring with an example?

Object Destructuring in JavaScript is a syntax feature that allows you to extract properties from an object and assign them to variables in a more concise way. It makes it easier to work with object properties, especially when you only need a subset of the properties or when the properties are deeply nested.

Basic Syntax:

The basic syntax of object destructuring looks like this:

        
            const { property1, property2 } = object;

Example 1: Basic Object Destructuring

        
            const person = {
                name: "John",
                age: 30,
                occupation: "Engineer"
              };
              
              const { name, age, occupation } = person; // Destructuring the properties from the object
              
              console.log(name); // "John"
              console.log(age); // 30
              console.log(occupation); // "Engineer"

In this example, we're extracting the name, age, and occupation properties from the person object and assigning them to new variables with the same names.

Example 2: Destructuring with Renaming

You can rename the variables when destructuring by using a colon (:) to specify the new variable name.

        
            const person = {
                name: "John",
                age: 30,
                occupation: "Engineer"
              };
              
              const { name: personName, age: personAge } = person; // Renaming properties during destructuring
              
              console.log(personName); // "John"
              console.log(personAge); // 30

Example 3: Destructuring with Default Values

If a property is missing from the object, you can assign it a default value during destructuring. 

        
            const person = {
                name: "John",
                age: 30
              };
              
              const { name, age, occupation = "Unemployed" } = person; // 'occupation' has a default value
              
              console.log(name); // "John"
              console.log(age); // 30
              console.log(occupation); // "Unemployed" (because it's not in the object)

Example 4: Nested Object Destructuring

You can destructure nested objects by referencing the property path.

        
            const person = {
                name: "John",
                age: 30,
                address: {
                  city: "New York",
                  zipCode: "10001"
                }
              };
              
              const { name, address: { city, zipCode } } = person; // Destructuring nested object 'address'
              
              console.log(name); // "John"
              console.log(city); // "New York"
              console.log(zipCode); // "10001"

Example 5: Destructuring in Function Parameters

Object destructuring can also be used directly in function parameters to extract values from an object passed as an argument.

        
            function displayPerson({ name, age, occupation }) {
                console.log(name); // "John"
                console.log(age); // 30
                console.log(occupation); // "Engineer"
              }
              
              const person = {
                name: "John",
                age: 30,
                occupation: "Engineer"
              };
              
              displayPerson(person); // Passing 'person' object to the function
